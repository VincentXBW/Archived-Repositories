# Skin Cancer Awareness
### A school CAT project: a simple awareness website to inform users about skin cancer — what it is, its types, how to prevent it, and why being sun smart matters.

## The goal of this project is to raise awareness about skin cancer through an informative and easy-to-use web page. It uses HTML, CSS, and static media to explain:
What skin cancer is
Different types of skin cancer
Prevention tips (e.g. sun exposure, sunscreen)
The importance of regular skin checks

## Features
Static, responsive-friendly webpage
Custom CSS styling
Visual elements: images and video to support learning
Clear, educational layout

### Getting Started
## Prerequisites

To run the project locally, you’ll need:
A modern web browser (Chrome, Firefox, Edge, Safari, etc.)
Basic text editor (VSCode, Sublime, etc.)
No server or backend needed.

## Installation
Clone the repo:

*git clone https://github.com/VincentXBW/Skin-Cancer-Awareness.git*

Or download the raw files
Open Schoolskincancer.html in your browser.
Make edits to HTML or CSS as wanted.

## Usage

Browse to learn about skin cancer.
Use in school presentations or share with friends.
Modify content (images, text, layout) to suit audience needs.
